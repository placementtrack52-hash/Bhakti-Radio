# 🪔 Bhakti Radio

A premium devotional radio web application built with Next.js 15, React, TypeScript, and Tailwind CSS.

## Getting Started

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
npm run start
```

## Adding Music

Drop your MP3 files into `public/audio/` with these filenames:

| File | Song |
|------|------|
| `hanuman-chalisa.mp3` | Hanuman Chalisa |
| `om-namah-shivaya.mp3` | Om Namah Shivaya |
| `gayatri-mantra.mp3` | Gayatri Mantra |
| `jai-shri-ram.mp3` | Jai Shri Ram |
| `govind-bolo.mp3` | Govind Bolo Hari Gopal |
| `durga-chalisa.mp3` | Durga Chalisa |
| `achyutam-keshavam.mp3` | Achyutam Keshavam |
| `ganesh-vandana.mp3` | Ganesh Vandana |
| `shiv-tandav.mp3` | Shiv Tandav Stotram |
| `mahalakshmi-ashtakam.mp3` | Mahalakshmi Ashtakam |

Drop your cover images into `public/images/` as `.webp` files.

## Deployment

Deploy to Vercel:
```bash
npx vercel
```

No environment variables, no database, no backend required.

## Features

- 🎵 Persistent audio player across all pages
- 🌌 Dynamic background (Morning/Afternoon/Evening/Night)
- 🔱 Shiva Peace Mode at night (Kailash mountains + mist)
- 📱 Mobile-first responsive design
- ♿ Accessible (WCAG 2.1 AA)
- ⚡ Optimized for Vercel deployment
